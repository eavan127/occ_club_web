Building VeriDeep

The Problem

With AI improving daily, it's becoming harder to tell if videos and photos are real or AI-generated. I built VeriDeep — a multi-layered deepfake detection platform that helped me win the Petronas Cybercrime Hackathon.

My Winning Strategy: LLM for Transcript Analysis

Most teams only analyzed visuals. I realized something key: scammers reveal themselves through what they SAY, not just how they look.

Using Google Gemini 2.0 Flash, I analyzed video transcripts to catch scam patterns that visual-only systems miss. This LLM-first approach was my secret weapon.

Why This Worked

  • LLM understands context and nuance — catches subtle red flags
  • Detects scam language like "I need money urgently"
  • Works across multiple languages
  • Complements visual detection for higher accuracy

The Multi-AI Approach

VeriDeep combines multiple detection methods — like checking for lies by looking at face, body language, and story coherence together:

Visual Analysis
Speech Analysis
Forensic Detection
Transcript Analysis

Key Features

  • Confidence scores (0-100%) with breakdown
  • Drag-and-drop upload with real-time progress
  • Images: under 5 seconds • Videos: 30-60 seconds
  • Chrome Extension for browser-based scanning

Key Takeaways

AI works best in combination. No single model is perfect, but combining them intelligently achieves remarkable accuracy.

Context matters. What someone says is often more revealing than how they look.

LLM isn't just for chatbots — it's a powerful cybersecurity tool.
